# Geweldsbeheersing

Leermateriaal voor de jaarlijkse toets geweldsbeheersing. Pure HTML en JavaScript, geen build, geen server, geen account nodig.

- `leerdoc/` leerstof, oefentoetsen, samenvatting, zoeken
- `spiekbriefje/` overzicht, checks en flitskaarten

## Lokaal gebruiken
Open `index.html` in een browser.

## Delen via GitHub Pages
1. Maak een repository op github.com en upload deze map (of `git push`).
2. Settings > Pages > Source: branch `main`, map `/ (root)`.
3. Deel de link die GitHub toont.

Artikelverwijzingen linken naar wetten.overheid.nl. Controleer altijd de actuele wettekst en de korpsvoorschriften.
